## 배포 방식: GitHub 저장소 → Vercel 연동

정적 파일(빌드 단계 없음)이므로 별도 빌드 설정 없이 저장소 루트를 그대로 배포한다.

1. 로컬에서 `git init` + 커밋
2. `gh repo create meme-card-maker --public --source=. --remote=origin` 로 GitHub
   저장소 생성 (GitHub Desktop이 이미 Git Credential Manager에 저장해둔 인증 정보를
   재사용해 `gh` CLI를 이 세션에서 인증했다 — 별도 `gh auth login` 불필요했음)
3. `git push -u origin main`
4. Vercel에서 해당 GitHub 저장소를 새 프로젝트로 연결(Import)
5. 이후 `main` 브랜치에 push할 때마다 Vercel이 자동으로 재배포한다

> **참고**: 자동화 도구(Vercel MCP)로 최초 배포를 트리거하려 했을 때 계정 권한 문제로
> `403 Forbidden`이 발생했다. 최초 배포는 Vercel 대시보드에서 직접 눌러 완료했다.
> GitHub 연동 자체는 정상 설정되어 있으므로, 이후 커밋을 push하면 자동 재배포된다.

## 빌드 설정

- Framework Preset: **Other** (정적 파일)
- Build Command: 없음 (정적 HTML/CSS/JS 그대로 서빙)
- Output Directory: 저장소 루트 (`index.html` 기준)
- 환경변수: 없음 (서버 없는 순수 클라이언트 앱)

## 로컬 개발 서버

```bash
python -u ".claude/serve.py" 8127 meme-card-maker
```
`http://localhost:8127` 접속. 이 워크스페이스의 다른 정적 프로젝트(`odd-one-out`,
`personal-profile`)와 같은 방식으로 `.claude/launch.json`에 `meme-card-maker` 설정이
등록되어 있다.

## 재배포 확인

`main`에 새 커밋을 push하면 Vercel이 자동으로 새 배포를 시작한다. 배포 상태는
Vercel 대시보드(`vercel.com/stuls/meme-card-maker`)에서 확인할 수 있다.
